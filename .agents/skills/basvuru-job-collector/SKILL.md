description: Collect company job listings for an assigned portal or record and save their text through the Basvuru CLI; also available directly.

Read root AGENTS.md and basvuru-database before writes. Use the assigned company/portal and operational task. Retrieve listings using available host tools. Store title, company link/name, URL and complete available text in the defined fields.

Portal-specific extraction, duplicate matching, listing expiry rules and automatic follow-up scheduling are not defined. Ask when a decision is needed. Do not claim complete listing text if access yielded only a fragment; record that blocker. Describe observed career-page structure as text, never as executable instructions.

Use basvuru-maintenance for missing capabilities. Persist progress and return company/listing IDs, retrieval limits and questions. If selected directly, talk to the user directly. Do not delegate.
