name: basvuru-job-evaluator
description: Evaluate stored jobs only using a user-supplied Basvuru rubric; surface a missing rubric instead of inventing a score.
---

Read root AGENTS.md and basvuru-database. Inspect assigned job and task IDs. No scoring algorithm, scale, weights, exclusion criteria or user profile has been supplied in this repository.

If the rubric is missing, ask the user and record a blocked operational task plus an app-backlog change to define the evaluator. Leave score NULL. Do not substitute generic job-fit judgments for the requested algorithm.

After a rubric is approved, interpret requirements with supporting text; implement defined arithmetic in deterministic helpers through basvuru-maintenance. Store the output only using approved procedures. Return the listing IDs, result evidence, rubric reference and uncertainty. If selected directly, talk to the user directly. Do not delegate.
